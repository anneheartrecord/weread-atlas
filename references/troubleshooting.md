# 排错

按现象查。每条都写了原因和处理办法。

## 拉数据

- **提示没有安装官方 weread-skills。** fetch.py 会依次到 `$WEREAD_SKILL_DIR`、`~/.claude/skills`、`~/.codex/skills`、`~/.agents/skills`、`~/.agent-harness/skills` 里找它的 SKILL.md，从里面读 `skill_version`。没装就让用户对自己的 agent 说 `Download https://cdn.weread.qq.com/skills/weread-skills.zip and install the skill`。装在别处时，设置 `WEREAD_SKILL_DIR` 指向那个目录。

- **退出码 3，打印了 upgrade_info。** 官方 skill 有新版本，服务端要求先升级。照 `upgrade_info.message` 升级官方 skill，再从头重跑 fetch。书脉自己不用改。

- **401、key 无效或 errcode 非 0。** 先确认 `echo ${WEREAD_API_KEY:0:4}` 输出的是 `wrk-`，再让用户到 https://weread.qq.com/r/weread-skills 重新复制。key 只放在环境变量里，不要写进库里或配置里。

- **HTTP 499 或超时。** 通常是有别的进程在同时调接口。脚本会自动重试 5 次；仍然失败的书会被记下，下次运行时自动补拉。

- **拉到一半断了，或者慢得不正常。** 直接重跑同一条命令。每本书拉完就单独缓存，笔记没变的书会跳过，从断开的地方接着拉。上一次停在哪、哪些书失败了，记在 `.atlas/fetch.json` 里，每拉完一本就更新一次。正常速度是每分钟二三十本，日志每 25 本打印一行进度；如果很久才出一行，而 `weread_client.py --ping` 一两秒就能返回，多半是网络或代理时好时坏，等网络稳定后再重跑。连续 5 本书的请求都在重试后失败时，脚本会自己停下，说明停在第几本和最后一次的错误，免得在断网时空等几个小时；最后一次是 HTTP 499 时，先找出同时在调接口的程序。

- **书比预想的少。** 书单来自 `/user/notebooks`，只包含有笔记的书。读过但没划线的书不在里面。

- **页面上读过的本数和有笔记的书数对不上。** 读过、读完的本数来自微信读书的阅读统计，有笔记的书来自笔记本列表，是两个接口各自的口径，对不上是正常的。书脉的书架和主题只按有笔记的书算。

- **很多书时长是 0。** 单本时长只能从每月读得最多的前 10 本里累加，没进过月度前 10 的书就是 0。这是接口口径决定的。

- **导入的书没有分类。** bookId 以 `CB_` 开头的是用户自己导入的书，接口不给分类。归纳主题时，用 `topics.json` 的 `assign` 给它们指定领域。

## 写笔记和主题卡片

- **topics.py 报校验错误。** 它会一次列出所有问题，什么都不写。按提示改 `topics.json`，常见的是书名写成了完整书名以外的其他写法，或者领域不在 `domains` 里。只想校验不想写文件时，加 `--check`。

- **主题删了，卡片还在。** topics.py 只列出多出来的旧卡片，不会删除。确认后由用户手动删除，或者经用户同意后再删。

- **用户改的内容被覆盖了。** 改动写在了生成区块的标记之间。区块内的内容每次运行都会重写，长期保留的补充要写在标记外面，主题的结论和观点改 `topics.json`。脚本发现区块被手动改过时，会先把整篇原文备份到 `.atlas/overwritten/` 再重写，并打印一行提示，可以从备份里把改动挪到标记外面。这个检查从装上新版后第一次运行开始生效，更早的改动没有指纹可比。

- **想改书的文件名。** 文件名在第一次运行时确定，之后不会再变，这是为了不让双链断掉。确实要改，就删掉 `.atlas/books.json` 重跑；旧文件名的笔记会留在原处，需要用户手动清理。

## 书房页

- **字体不是楷体，或者封面不显示。** 字体从 jsDelivr 加载，封面来自微信读书的图片服务器，都需要联网。离线打开时会退回系统字体，封面显示空白。

- **render.py 有警告。** 通常是某篇笔记被手动改坏了，比如 frontmatter 缺了结尾的 `---`。警告里有文件名，修好后重新渲染。被跳过的笔记不会出现在页面上。

- **分享检查的编号对不上。** `--exclude` 用的编号来自最近一次列表，每次都先不带参数运行一遍，再按新编号排除。
